# ParlaConClaudio 1.1.2

Avvisi vocali in fila, uno alla volta.

## Novità

- **Un suono, poi le voci in fila.** Quando più sessioni di Claude Code o Codex finiscono o chiedono aiuto insieme senti un solo suono, poi una voce per progetto, una dopo l'altra. Prima suoni e voci si sovrapponevano.
- **Prima chi chiede aiuto.** Permessi, domande e attese di un tuo input parlano per primi, poi chi ha finito, poi i subagenti.
- **Nessun annuncio perso.** Prima, se due progetti avvisavano entro 300 ms, uno dei due spariva. Ora gli avvisi ripetuti si accorpano solo dentro la stessa sessione.
- **Easter egg di Frisco** solo dopo l'ultima voce in coda.

## Installazione

Chiudi l'app in esecuzione prima di aggiornare.
