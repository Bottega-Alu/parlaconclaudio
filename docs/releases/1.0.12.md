# parlaconclaudio 1.0.12

Versione consolidata dalla 1.0.10 e dalla 1.0.11-test.2, valutate dall'utente.
L'installer locale è preparato sul branch `release/1.0.12`; merge su main,
tag e pubblicazione GitHub restano operazioni separate.

## Migliorie incluse

- Pannello Windows dalla tray con stato, dettatura, trascrizione file, microfono,
  motore, memoria GPU e collegamenti Codex/Claude Code.
- Icona statica a riposo; renderer NumPy con antialiasing e icona finale a 64 px.
  Durante il lavoro i frame sono riutilizzati tramite una cache limitata.
- Registrazioni consecutive protette dai watchdog precedenti, recupero dagli
  errori del microfono e accesso serializzato al motore STT.
- Correzione LLM della dettatura con budget complessivo di tre secondi;
  conservazione del testo originale alla scadenza. Fallback STT sugli errori
  quando abilitato e feedback sugli errori di consegna.
- Comando per liberare la memoria GPU distinto dalla ricarica del modello.
- Worker vocale Codex senza console, con conservazione del virtualenv e del
  payload UTF-8. La correzione non cambia i comandi degli hook già approvati.
- Installer con spiegazione dell'app, scelta del profilo e due caselle
  indipendenti Claude Code/Codex, selezionate inizialmente su nuova installazione.
  Su aggiornamento vengono rispettate le scelte precedenti.

## Installazione

Chiudi dalla tray l'app normale e le versioni TEST prima dell'aggiornamento.
La 1.0.12 riusa l'identità dell'app normale e la sua precedente cartella di
installazione, se registrata; su installazione nuova propone
`%LOCALAPPDATA%\Programs\VoiceBridge`. Le versioni TEST rimangono separate:
avvia la 1.0.12 dal collegamento normale, non dal collegamento TEST.

Impostazioni audio e configurazioni degli agenti restano condivise. Se una
casella degli hook è deselezionata, il relativo collegamento esistente rimane
intatto. Per le integrazioni selezionate, il setup può aggiornare gli interpreti
e le copie dello script usati dagli hook, salvando un backup dello script prima
di sostituirlo. I file di configurazione degli hook sono scritti con backup e
sostituzione atomica, preservando gli altri hook.

Per nuovi comandi Codex verifica gli hook personalmente in `/hooks`. Il setup
non approva gli hook e non installa le CLI degli agenti. L'avvio automatico è
una scelta separata, inizialmente disattivata su nuova installazione.

La dettatura locale richiede una GPU NVIDIA compatibile. Senza GPU configura
Groq o Deepgram dal menu della tray; il profilo senza CUDA evita il download
inutilizzato del modello locale. Il primo setup richiede rete e spazio per le
dipendenze; il file installer non contiene già l'intero runtime.

## Verifica

La suite include test di regressione su renderer, cache, registrazioni, selezione
degli hook e worker Windows reale senza console. La misura precedente di 60
secondi sull'animatore isolato ha rilevato zero aggiornamenti dell'icona e zero
byte scritti a riposo; non è una misura dell'intero bridge installato.

Il Sound Pack Creator resta una proposta: non è incluso in questa versione.
