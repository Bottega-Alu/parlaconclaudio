## English

**Speak your prompts. Hear your agents.**

I built ParlaConClaudio, an open-source Windows app that lets you dictate into the app where you're typing and hear when Claude Code or Codex finishes or needs your attention.

It supports local Whisper on NVIDIA GPUs or cloud recognition with Groq/Deepgram, keyboard or mouse triggers, light/dark themes, and an Italian, English or Brazilian Portuguese interface. There is a Windows installer; you do not need a GPU to use a cloud engine.

If you work with coding agents or dictate emails and notes, I'd love your feedback. Try it, open an issue, or leave a star if you find it useful:
https://github.com/Bottega-Alu/parlaconclaudio

## Italiano

**Detta i tuoi prompt. Ascolta i tuoi agenti.**

Ho creato ParlaConClaudio, un'app open source per Windows: detti dove stai scrivendo e ascolti gli avvisi quando Claude Code o Codex finiscono o hanno bisogno di te.

Puoi usare Whisper in locale su GPU NVIDIA oppure Groq/Deepgram nel cloud, attivare la dettatura da tastiera o mouse e scegliere interfaccia e annunci in italiano, inglese o portoghese brasiliano. C'è un installer per Windows; per il cloud non serve una GPU.

Se usi agenti di coding o detti email e appunti, mi farebbe piacere sapere come ti trovi. Provala, segnala un problema o lascia una stella se ti è utile:
https://github.com/Bottega-Alu/parlaconclaudio

## Português BR

**Dite seus prompts. Ouça seus agentes.**

Criei o ParlaConClaudio, um app de código aberto para Windows: você dita no aplicativo em que está escrevendo e ouve avisos quando o Claude Code ou o Codex termina ou precisa de você.

Funciona com Whisper local em GPU NVIDIA ou reconhecimento na nuvem com Groq/Deepgram. Tem atalhos de teclado ou mouse, temas claro/escuro e interface e avisos em português brasileiro, inglês ou italiano. Há um instalador para Windows; a opção de nuvem não exige GPU.

Se você usa agentes de programação ou dita e-mails e anotações, gostaria de ouvir sua opinião. Experimente, abra uma issue ou deixe uma estrela se achar útil:
https://github.com/Bottega-Alu/parlaconclaudio
